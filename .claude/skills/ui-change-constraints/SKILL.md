# UI・デザイン変更時の制約

詳細な変更履歴・確定仕様は [docs/implementation_guide_v2.md](../../../docs/implementation_guide_v2.md) を参照。ここでは変更時に必ず守るべき制約のみをまとめる。

## 変更禁止事項

- トップバーの背景色（`#647cc0`）・AUTHORING MODEラベル色・アイコン
- 既存のページレイアウト構造（`.main` / `.view` / `.page`）
- 既存JavaScript関数の挙動（ロジックそのもの）
- 既存の色変数・テーマカラー（サイドバー `#353c47` 等）

変更前後で必ず動作確認を行うこと。

## ボタン位置・サイズの保存形式（移行中）

異なる画面サイズ間でのズレ対策として、ボタン位置・サイズを絶対px値ではなく**紙面に対する比率（0〜1）**で保存する設計に移行中。

- 保存：`xRatio` / `yRatio` / `wRatio` / `hRatio` を紙面幅・高さから算出して記録
- 読込：比率から絶対px値に逆算して配置
- **後方互換性が必須**：旧形式（絶対値のみ、`xRatio` 等が存在しない）のJSONを読み込んだ場合は絶対値をそのまま使うフォールバックを必ず実装する

このデータ形式に触れるコード（アノテーションの位置・サイズを扱う箇所全般）を変更する際は、新旧両形式に対応しているか確認すること。
