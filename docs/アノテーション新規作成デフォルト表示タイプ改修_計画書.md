# アノテーション新規作成時のデフォルト表示タイプ改修 計画書

作成日: 2026-07-17
対象種別: 音声再生（audio）・動画再生（video）・Plusファイル（plusfile）・ページリンク（pagelink）・外部リンク（externallink）

## 背景・症状

「マーカー」表示タイプはコミット 0342b5d で選択UIから非表示化し、新規作成ポップアップのデフォルトも「アイコン」に変更済み。しかし、対象5種別を紙面上に新規設置する際、依然として表示タイプ「マーカー」でアノテーションが作成されるケースが残っている。

## 原因

新規作成には2つの経路があり、前回の修正はクリック作成経路のみをカバーしていた。

1. **クリック作成**（ほぼ移動なしでマウスを離す）: クイック作成ポップアップが開く。`buildSpecificFields` のデフォルトが `'icon'` になっているため対応済み（正常）。
2. **ドラッグ作成**（矩形を描いてマウスを離す）: ポップアップを出さず即時作成する経路。この経路が **`annDisplayType = 'marker'` を明示的にフォームへ注入してから `confirmAnnotation()` を呼んでいる**ため、マーカー非表示化後もマーカー型で作成されてしまう。

ドラッグ作成の実装は以下の2箇所に重複して存在する（役割分担はコメント参照。ページ内リリースは 2-a、ページ外リリースは 2-b が処理する）:

- **2-a**: `app/js/annotation-interaction.js` の `onPageMouseUp` 内（現在551-566行）。「ドラッグ作成：ポップアップなし・マーカー形式で即時作成」のコメントに続き、`#dialogFormSpecific` 内の `#annDisplayType` に `'marker'` を設定（無ければ hidden input を `data-qc-inject` 付きで注入）して `confirmAnnotation(type)` を呼ぶ。
- **2-b**: `app/js/main.js` の document レベル mouseup リスナー内（現在229-263行）。2-a と同一構造の重複実装。

さらに二次影響として、ドラッグ作成でマーカー型が作られると、連続作成モードの引き継ぎ（`lastNewAnnData[type]`、`confirmAnnotation` 内で保存）に `annDisplayType: 'marker'` が記録され、**その後のクリック作成ポップアップの初期値までマーカー（非表示のまま checked）になる**。ユーザーが編集画面で目にした「初期値がマーカー」はこの伝播も含む。

## 修正方針（ユーザー確認済み）

ドラッグ作成経路の注入値を `'marker'` から **`'page-color'`（紙面カラー）** に変更する。

- 理由: アイコン型は固定48pxの円形であり、ドラッグで描いた矩形サイズを活かせない。紙面カラー型は矩形をそのまま透明ホットスポットとして使うため、「矩形を描いて配置する」というドラッグ操作の意図と合致する。
- クリック作成（ポップアップ）は現状のまま「アイコン」デフォルトを維持する（変更しない）。
- この変更により、ドラッグ作成後の連続作成引き継ぎ（`lastNewAnnData`）には `'page-color'` が記録される。次にクリック作成した際のポップアップ初期値が紙面カラーになるのは、連続作成モードの既存仕様（直前の設定を引き継ぐ）通りの挙動として許容する。

## 修正箇所

### 1. `app/js/annotation-interaction.js`（onPageMouseUp 内、現在551-563行付近）

`_dtEl.value = 'marker';` および hidden input 注入時の `_inp.value = 'marker';` を、いずれも `'page-color'` に変更する。直前のコメント「マーカー形式で即時作成」も「紙面カラー形式で即時作成」に更新する。

### 2. `app/js/main.js`（document mouseup リスナー内、現在247-260行付近）

同上。`'marker'` 2箇所を `'page-color'` に変更し、コメントも更新する。

### 3. `app/js/annotation-dialog.js`（confirmAnnotation 内、現在1488行）

`const displayType = savedData.annDisplayType || 'marker';` のフォールバックを `|| 'icon'` に変更する。

- 通常はフォームに `annDisplayType` hidden input が必ず存在するためこのフォールバックはほぼ到達しないが、「初期値はアイコン」という本改修の趣旨に合わせ、未指定時に非表示のマーカー型が暗黙に作られる余地を塞ぐ。
- 既存アノテーションの更新時（isUpdate）は `savedData.annDisplayType` に `'marker'` が明示的に入っている（truthy）ためフォールバックは発動せず、既存マーカー型の編集・再保存には影響しない。

### 変更しない箇所（誤って触らないこと）

- `app/js/annotation-dialog.js` の `openEditPopup` 内 `prevData.annDisplayType || 'marker'`（現在43行）: 既存要素の編集時、クラスがアイコン型/画像型でない `.ann-object` は実際にマーカー型（レガシー要素）であるため、このフォールバックは正しい。変更するとレガシーマーカーの編集が壊れる。
- `app/js/annotation-interaction.js` 321行付近の `renderAnnObjectContent(el, snap.type, 'marker', ...)`: Undo/Redo でマーカー型スナップショットを復元する処理。変更不可。
- `confirmAnnotation` 内のマーカー型描画分岐そのもの（既存マーカーの更新用に残す）。
- クリック作成（クイック作成ポップアップ）のデフォルト（アイコン）。

## テスト観点

1. 対象5種別それぞれで、**ドラッグ**（10px以上の矩形を描く）で新規作成し、生成された要素が `.ann-object.dt-page-color`（紙面カラー型）で、ドラッグした矩形の位置・サイズを持つこと
2. 対象5種別それぞれで、**クリック**（ほぼ移動なし）で新規作成ポップアップを開き、表示タイプ初期値が「アイコン」のままであること（リグレッション確認）
3. ドラッグ作成の直後にクリック作成した場合、連続作成モードの引き継ぎによりポップアップ初期値が「紙面カラー」になること（既存仕様通りの伝播であることの確認）
4. 既存のマーカー型アノテーション（本改修前に作成済み、または LIBRO book 由来）をダブルクリックで開いて「更新する」を押しても、マーカー型のまま見た目・データが維持されること
5. ページ外でマウスを離すドラッグ作成（main.js 側の経路）でも 1 と同じ結果になること
6. Undo/Redo でマーカー型・紙面カラー型それぞれの作成取り消し・やり直しが正常に動作すること
