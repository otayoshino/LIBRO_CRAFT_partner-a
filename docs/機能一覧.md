# ContentsBuilder（LIBRO＋CRAFT）機能一覧

現在 `app/` に実装されている機能の一覧（コード調査ベース、2026-09-01時点。反映済みの最終コミットは2026-08-20分）。
「機能名称 | 動作内容」形式で記載する。UIから到達できない無効化中の機能は末尾の「無効化・未実装」節にまとめる。

---

## 1. ファイル入出力

| 機能名称 | 動作内容 |
| --- | --- |
| ZIP読込 | ヘッダーの「ZIP読込」ボタン、または紙面中央の「LIBRO bookを読み込む（ZIP）」ボタンでファイル選択ダイアログを開く。ZIPルート直下に `index.json` があればLIBRO book形式、無ければ独自ZIP形式（`annotations.json`＋メディア）として自動判別して読み込む（`storage.js: handleZipFile`）。 |
| LIBRO book読込 | ページ画像（暗号化）を復号してcanvas描画し、`p####.json` のアノテーションを復元する。既知種別はCRAFTオブジェクト化し、未知アノテーション／Hide-Showペア／拡張トグルネットワーク／LIBRO由来大問ボタンは生データとして保持する。未暗号化アセットを検出した場合は件数をトースト表示する。 |
| 独自ZIP読込 | ZIP内の全ファイルをBlobURL化して `mediaBlobs` にキャッシュし、`annotations.json` からアノテーションを復元する。 |
| LIBRO形式で書き出す | 読み込んだLIBRO bookの構造を維持したままZIPを再生成して保存する（`storage.js: saveAnnotationsAsLibroBook` → `libro-format.js: buildLibroBookExport`）。LIBRO book未読込時、および見開き表示中はボタンが非活性。 |
| 書き出し対象種別 | ページリンク／外部リンク／音声再生／Plusファイル／付箋（Hide-Show）／答ボタン／大問ボタン／動画（内部ファイル＝toMovieBNR、J-stream＝toMovie）。答ボタン・新規作成の大問ボタンはHide-Showペアへ変換して書き出す。LIBRO由来の大問ボタンは未編集なら生データを無変更で書き戻す。**書き出し対象外は証明ボタンと動画の外部タグ指定のみ**（トーストで警告）。証明ボタンは本体に加え、紐付く付箋・紐付く大問ボタンも除外される。 |
| メディアのZIP格納 | 音声は `sounds/`、アイコン画像・ボタン画像は `annots/`、動画内部ファイルは `video/in/<名前>.mp4` として格納する。未暗号化だった既存アセットは書き出し時に強制暗号化する。 |
| 自動保存（オートセーブ） | DOMのアノテーション状態をIndexedDB（`ContentsBuilderAutoSave`）へスナップショット保存する。操作後3秒のデバウンス保存＋30秒間隔の定期保存の二重運用（`autosave.js`）。 |
| 自動保存の復元 | 同一bookのZIPを読み込んだ直後に、保存済みスナップショットがあれば復元確認を表示する（`checkAndPromptRestoreForBook`）。 |

## 2. ページ表示・ナビゲーション

| 機能名称 | 動作内容 |
| --- | --- |
| 次ページ／前ページ | ヘッダーの前後ボタン、紙面左右のスライドナビ、矢印キー（→/↓＝次、←/↑＝前）で移動する。右綴じbook（`index.json` の `rl-reading-order: "right"`）では読み進め方向が反転する。 |
| 先頭ページ／最終ページ | ヘッダー端のボタンで先頭・最終ページへジャンプする。右綴じbookでは左右の意味が入れ替わる。 |
| ページ番号直接入力 | ヘッダーの数値入力へページ番号を入力してEnter/フォーカスアウトで移動する。範囲外の値は元の値に戻す。 |
| 目次（TOC）ジャンプ | `index.json` の `configs['toc-page']` が指すページへ移動する。値が無い／範囲外の場合はボタンが非活性。 |
| ページ送りボタンの活性制御 | 先頭・末尾到達時に該当方向のボタンとスライドナビを非活性／非表示にする（右綴じ時は左右反転）。 |
| 見開き表示／単ページ表示の切替 | ヘッダーの2ボタン（`viewSingleBtn` / `viewSpreadBtn` → `page-view.js: setViewMode`）で切り替える。見開き表示は **book に既存の見開き合成ページ画像をそのまま表示する閲覧専用モード**で、アノテーションの表示・編集・書き出し・自動保存は行わない。切替時はズーム100%・パン0にリセットし、単ページへ戻る際に「見開きへ入る直前の基準サイズ→戻り後の基準サイズ」で座標を1回だけ変換する。 |
| 見開きボタンの活性制御 | 見開きボタンは、book未読込／bookが見開き合成ページを持たない／単ページ表示中で現在ページがどの `sub-pages` にも含まれない（表紙など）場合に非活性。判定は現在ページ依存のためページ移動のたびに更新する（`updateViewModeButtonStates`）。 |
| 見開き⇔単ページの起点ページ | 単ページ→見開きは現在ページを含む見開きへ移動する（対応が無ければ切り替えない）。見開き→単ページは、その見開きが含む単ページ番号のうち**若い方**を起点にする。 |
| 編集対象ページ列 | 読込時に `configs['real-page-count']` を超える見開き合成ページを編集用ページ列（`state.singlePages`）から除外する。合成ページの生データは保持され、書き出し時は `indexJson.pages` 全件を駆動元に無改変で書き戻す。 |
| 見開きページバッジ | 見開き表示中は「見開き」バッジを表示する。 |
| 見開きページの編集ロック | 見開き表示中はグレーアウトオーバーレイ「見開きページの編集はできません」を重ねて編集不可を明示する。 |
| ページ別アノテーション表示 | `data-page` が現在ページと一致するアノテーションのみ表示する（他ページ分は `ann-hidden-page` で非表示）。 |
| 拡大／縮小 | ヘッダーの＋/−ボタンで10%刻み。範囲は50%〜400%で、上限・下限に達するとボタンを非活性化する。 |
| ホイールズーム | 紙面上のホイール操作で10%刻みにズームする。マウスカーソル位置を中心に拡大縮小する。スペースキー押下中（パンモード）は無効。 |
| 高さフィット／幅フィット | ヘッダーのフィットボタンでビューエリアの高さ基準／幅基準にページ基準サイズを合わせる。初期状態は高さフィット。 |
| スペース＋ドラッグでパン | スペースキー押下中はカーソルがパンモードになり、ドラッグで紙面全体を平行移動する。キーを離すと解除。 |
| ヘッダー折りたたみ | ヘッダーの折りたたみボタンでナビ全体を隠し、画面上部の展開ボタンで復帰する。 |

## 3. モード切替

| 機能名称 | 動作内容 |
| --- | --- |
| 閲覧モードに切替 | サイドバーのモード切替ボタンで閲覧モードへ。描画モードを解除し全選択を解除、`body.is-view-mode` を付与してオーサリング操作を止める。 |
| 編集モードに切替 | 閲覧モード中の付箋の開閉状態・証明ボタンによる枠線表示を全てリセットし、押下状態のボタン画像も通常画像へ戻す。大問ボタンの開閉状態（`daimonOpen`）も破棄する。 |
| 活性制御 | book未読込時（`state.currentBookId` なし）はオーサリングパネルの各項目とモード切替ボタンをグレーアウトして操作不可にする。 |

## 4. アノテーション作成

| 機能名称 | 動作内容 |
| --- | --- |
| 種別選択（描画モード） | オーサリングパネルの各項目クリックで描画モードに入る（付箋／音声再生／動画再生／Plusファイル／ページリンク／外部リンク）。Escで解除。 |
| ドラッグ作成 | 紙面上をドラッグして矩形を描くと、その矩形サイズで「紙面カラー型」オブジェクトを即時作成する（クリック扱いのしきい値は付箋のみ `STICKY_MIN_SIZE_PX`＝4px、それ以外は10px。細い解答欄を覆えるようにするため）。 |
| クリック作成（クイック作成ポップアップ） | 紙面をクリックすると作成ポップアップが開き、位置・サイズ・表示タイプ・種別固有設定を入力して「作成する」で確定する。タイトルバードラッグでポップアップを移動可能。表示中は紙面向けショートカットを抑止しEscのみ受け付ける。 |
| 表示タイプ | 非付箋系オブジェクトは「紙面カラー型／アイコン型／マーカー型／画像型」の4種から選択する。 |
| 前回値の引き継ぎ | 種別ごとに直前に作成した設定値（`lastNewAnnData`）を次回の新規作成フォームの初期値として引き継ぐ。 |
| アイコン画像アップロード | アイコン型・画像型でドロップゾーンへ画像をドラッグ＆ドロップまたは選択してアップロードする。上限5MB・一辺4096px。書き出し時は `annots/xxxx.png` として格納する。 |
| 音声ファイル添付 | 音声の設定欄にMP3ファイルをドロップ（またはゾーンをクリックして選択）して紐付ける。BlobURL化して `mediaBlobs` へ格納し、プレビュー再生と書き出しに使う。**動画にはファイル添付の導線は無い**（下記「動画再生」を参照）。 |

### 種別ごとの設定項目

| 機能名称 | 動作内容 |
| --- | --- |
| ページリンク | 「リンク先」にページ番号を指定する。閲覧モードでクリックすると該当ページへ移動する。 |
| 外部リンク | 「リンク先URL」を指定する。閲覧モードでクリックすると別タブで開く。`http`/`https` 以外（LIBRO側でevalされる `toFlashcard(...)` 等の擬似関数文字列）はトースト「CRAFTでは閲覧できません」を出すだけで開かない。設定値そのものは加工せず保持・書き出しする。 |
| Plusファイル | 「表示方法」（ページ内／別タブ／フローティング）と「ディレクトリ名」を指定する。Plusファイルの実体はCRAFTの管理対象外のため、閲覧モードでは実体を読み込まず「CRAFTでは閲覧できません」表示になる（別タブ＝メッセージページ、ページ内＝背景グレーアウト付きモーダル、フローティング＝タイトルバードラッグ移動可のポップアップ）。 |
| 音声再生 | 「ファイル名」（拡張子 `.mp3` 除く）と「再生方法」（コントローラーあり／なし）を指定する。ファイル名欄にはbook同梱音声の候補を `<datalist>` で提示する（自由入力も可）。閲覧モードでは、ありならドラッグ移動可能なフローティングプレーヤー、なしなら即時再生。該当ファイルがbookに無い場合はトースト「音声ファイル「〜.mp3」が見つかりません」を出して再生しない。 |
| 動画再生 | **CRAFTから動画ファイルをドラッグ＆ドロップで配置する方式は存在しない。** 動画は「①J-streamのデータを参照する」「②LIBRO＋へあらかじめ登録された動画を参照する（実装予定）」の2方式のみで、いずれも**パラメータを渡して参照先を指定する**。現在UIから新規作成できるのは①のJ-stream指定のみ（`annVideoSrc` 既定値 `'2'`）で、「Jストリームディレクトリ／企業ID／難読化ID」を入力する。②に相当する「内部ファイル」と、旧仕様の「外部動画をタグで追加」のラジオ選択肢は非表示化されており、既存データを編集する場合のみ表示される（機能・データは残置）。共通で「表示方法」（ページ内／別タブ）を指定するが、LIBRO＋上では常に別タブ再生となる旨を欄下に注記表示する。**閲覧モードでは入力方式によらず常に「CRAFTでは閲覧できません」を表示する**（別タブ＝メッセージページ、ページ内＝動画モーダル内に表示）。 |
| J-stream入力値の検証 | ディレクトリ・企業ID・難読化IDを入力欄ごとに検証し、エラーメッセージを欄下に表示する（`jstream-validate.js`）。 |
| 付箋 | 「開閉方式」（通常開閉／表示ボタン削除）と塗り色（青／緑／黄／紙色）を指定する。LIBRO由来の既存付箋は閉側画像が元データ由来のため開閉方式・色の変更対象外。 |

## 5. アノテーション編集操作

| 機能名称 | 動作内容 |
| --- | --- |
| 単一選択 | オブジェクトをクリックすると他の選択を解除して単独選択し、ヘッダー詳細設定パネルにその設定を表示する。 |
| 追加選択（Shift＋クリック） | Shiftを押しながらクリックで選択に追加／選択から除外する。 |
| 範囲選択（ドラッグ選択） | 紙面またはグレーエリアから空白をドラッグして矩形を描き、矩形に含まれるオブジェクトを一括選択する。Shift併用で既存選択へ追加。5px未満はクリック扱いで選択解除しない。 |
| 全選択 | `Ctrl/Cmd + A` で現在ページの全オブジェクトを選択する。入力欄フォーカス中は無効。 |
| 選択解除 | Escで描画モード解除・ドラッグ選択キャンセル・ダイアログクローズを行う。右クリック／ウィンドウのフォーカス喪失でもドラッグ選択をキャンセルする。 |
| ドラッグ移動 | 選択オブジェクトをドラッグして移動する。紙面外へはみ出さないようクランプする。複数選択時はグループごと相対位置を保って移動する。 |
| Shift＋ドラッグ移動 | Shiftを押しながらドラッグすると水平または垂直方向に固定して移動する。 |
| Alt＋ドラッグ複製 | Altを押しながらドラッグすると、選択オブジェクト（複数可）を複製して移動する。 |
| リサイズ | 選択オブジェクトの8方向ハンドル（辺中点＋コーナー）をドラッグしてサイズ変更する。 |
| Shift＋コーナードラッグ | コーナーハンドルをShift併用でドラッグすると軸を固定してリサイズする（縦横比ロック対象は除く）。 |
| 縦横比ロック | アイコン型オブジェクト、および画像素材を設定した大問／答／証明ボタンはコーナー4点のみのハンドルとなり、縦横比を維持してリサイズする。 |
| 数値入力での位置・サイズ変更 | ヘッダー詳細設定パネルのX／Y／W／Hをスピンボタンまたは直接入力で変更する。紙面実寸px基準で表示・入力し、内部座標へ変換して即時反映する。 |
| 複数選択パネル | 2件以上選択時は詳細設定パネルが複数選択用表示（外接矩形の位置・サイズ）へ切り替わる。 |
| ダブルクリック編集 | オブジェクトをダブルクリックすると編集ポップアップが開き、種別固有設定を編集できる。 |
| 削除 | Delete／Backspaceキーで選択オブジェクトを削除する。入力欄フォーカス中・閲覧モード中は無効。 |
| コピー | `Ctrl/Cmd + C` で選択オブジェクトを内部クリップボードへコピーする。 |
| 切り取り | `Ctrl/Cmd + X` でコピー＋削除する。閲覧モード中は無効。 |
| 貼り付け | `Ctrl/Cmd + V` でクリップボードの内容を現在ページへ貼り付ける。 |
| 整列 | ヘッダー「整列」パネルの6ボタンで、2件以上の選択オブジェクトを外接矩形基準に整列する（水平左／水平中央／水平右／垂直上／垂直中央／垂直下）。 |
| Undo | `Ctrl/Cmd + Z` で直前の操作を取り消す。履歴上限50件。対象操作：作成／削除／移動／リサイズ／プロパティ変更／グループ化／付箋非表示／大問・答・証明ボタン作成。 |
| Redo | `Ctrl/Cmd + Shift + Z` で取り消した操作をやり直す。 |

## 6. 付箋パーツ操作

| 機能名称 | 動作内容 |
| --- | --- |
| 大問ボタン作成 | 選択中の付箋・証明ボタン（1件以上）に大問IDを付与し、大問ボタンを配置する。配置位置は紐付け対象の先頭オブジェクト（最も上・同率なら最も左）の**左横・上端揃え**（上方向の他オブジェクトとの干渉を避けるため。証明ボタンのみ従来どおり選択グループ左上の少し上）。紙面外へははみ出さないようクランプする。証明ボタン傘下の付箋も間接制御対象として同時に紐付ける。作成時点の環境設定「制御ボタンアイコン」文言（大問／ALL／解答）をボタンごとに保持する。 |
| 大問制御範囲の囲み線 | 大問IDを持つオブジェクトを選択すると、同一大問IDのメンバー全体の外接矩形に囲み線（`.daimon-group-box`）を表示する。配下付箋に紐付く答ボタンも `kotaeId` から逆引きして囲み線に含める。移動・リサイズ・ズームに追従し、選択解除で消える。 |
| 大問ボタン（閲覧モード） | クリックで紐付き付箋を一括開閉する。自身の開閉状態（`daimonOpen`）を基準に判定するため、個別に開閉した付箋があっても一括動作が乱れない。押下時はボタン画像を押下状態へ差し替える。 |
| 答ボタン作成 | 選択中の付箋（1件以上）に答IDを付与し、背景を白へ変更、開閉方式を「表示ボタン削除」に既定適用したうえで答ボタンを配置する（配置位置は大問ボタンと同じく先頭付箋の左横・上端揃え）。元の背景色・開閉方式は復帰用に退避する。 |
| 答ボタン（閲覧モード） | クリックで紐付き付箋の表示／非表示を一括トグルし、ボタン画像を押下状態へ差し替える。 |
| 付箋グループ切替 | 選択中の付箋（2件以上）をグループ化する。全員がグループ済みの場合は解除する。グループ化された付箋は閲覧モードでどれか1つをクリックすると全員が同時に開閉する。 |
| 付箋の開閉（閲覧モード） | 付箋クリックで表示／非表示をトグルする。グループ所属時はグループ全体が連動する。 |
| ボタン拡大率 | 大問／答／証明ボタンの詳細設定で拡大率（0.5〜3.0、0.1刻み）を指定する。 |
| ボタン画像素材 | 大問／答／証明ボタンにSVG/PNG画像をドロップして差し替える。押下状態画像は色反転で自動生成する。「画像をクリアして既定のボタンに戻す」で解除。 |

## 7. インデックス（目次）編集

| 機能名称 | 動作内容 |
| --- | --- |
| インデックス編集モーダル | ヘッダーのインデックス編集ボタンで `index.json` の `outline`（最大3階層）を編集するモーダルを開く。LIBRO book未読込時は非活性。 |
| 項目の追加 | 「＋ 項目を追加」で第1階層の空行を末尾に追加し、リスト末尾へスクロールする。 |
| 階層・見出し・遷移先の編集 | 各行で階層（1〜3）・見出し文字列・遷移先ページ番号を編集する。4階層以上の既存データは3階層に丸めて読み込む。 |
| 遷移先ページの上限 | 遷移先に指定できるのは `real-page-count` までの単ページのみで、**見開き合成ページを新規に指定することはできない**。ただし読込時からその値のままの行だけは例外的に許容し、既存bookの見開きナビ目次項目を壊さない（一度単ページ側へ書き換えた行は合成ページ番号へ戻せない片道仕様）。 |
| BOM文字の往復維持 | 見出し先頭のU+FEFFは表示時に除去し、書き出し時に付与する。未編集行は元の生文字列をそのまま維持する。 |
| 確定・キャンセル | OKで検証のうえ `state.libroBook.indexJson.outline` へ書き戻し（実ファイル反映は「LIBRO形式で書き出す」実行時）。キャンセル／Escで破棄する。 |

| `Ctrl/Cmd + Shift + Z` | Redo（やり直し）。 |

| `Ctrl/Cmd + C` | 選択オブジェクトをコピー。 |

| `→` / `↓` | 次ページへ移動。 |
| `←` / `↑` | 前ページへ移動。 |
