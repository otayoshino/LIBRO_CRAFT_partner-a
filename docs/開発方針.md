# LIBRO＋CRAFT の開発方針

create: 2026-06-30
update: 2026-07-06

## 概要

モックから動作可能な開発アプリへ昇格させる。
現在未実装の機能を洗い出し、担当者別に開発を進める。

## スケジュール

### マイルストーン

1. 受け入れテストが可能な状態のスタンドアロン版を用意 7月24日
2. 受け入れテスト 7月27日 〜（後藤さんに確認）

### LIBRO＋CRAFT のシステム概略

LIBRO から ZIP ファイルを受け取り、LIBRO＋CRAFT で展開する。
LIBRO＋CRAFT 上でアノテーションの追加や編集を可能とし、最終的に編集した ZIP（更新済み）を保存する。

## 実装済み機能

- [x] アーティファクトをモジュール分け（`app/js/` 配下にES Modulesで分割済み）
- [x] アノテーションや背景画像の復号化と暗号化（Pbve2000）
- [x] book ファイル（Zip）の読み書き
- [x] 見開き部分の表示とアノテーション
- [x] book json の読み書きモジュール（`app/js/libro-format.js`）
- [x] アノテーションの追加・再編集と json 編集の紐づけ（ページリンク・外部リンク・音声再生・Plusファイル・動画の一部）
- [x] JSON単体読み込み機能の廃止（ZIP読込に統一）

## 未実装機能（八木澤が対応すること）

- [ ] 証明ボタンのLIBRO書き出し対応（現状は本体・紐付く付箋・紐付く大問ボタンがまとめて書き出しから除外される。**当面は実装予定なし**）
