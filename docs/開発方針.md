# LIBRO＋CRAFT の開発方針

create: 2026-06-30

## 概要

モックから動作可能な開発アプリへ昇格させる
現在未実装の機能を洗い出し

## スケジュール

### マイスストン

1. 受け入れテストが可能な状態のスタンドアロン版を用意 7月24日
2. 受け入れテスト 7月27日 〜（後藤さんに確認）

### LIBRO＋CRAFT のシステム概略

LIBRO から ZIP ファイルを受け取り、LIBRO＋CRAFT で展開する。
LIBRO＋CRAFT 上でアノテーションの追加や編集を可能とし、最終的に編集した ZIP（更新済み）を保存する

- [ ] アノテーションや背景画像の復号化と暗号化
- [ ] book ファイル（Zip）の読み書き
- [ ] 見開き部分の表示とアノテーション
- [ ] book json の読み書きモジュール
- [ ] アノテーションの追加・再編集と json 編集を紐づける
